Key vocabulary

Expected returnThe average return you'd expect: each possible return × its chance, added up.
Standard deviationHow much returns swing around their average. Bigger = more volatile.
Risk premiumThe extra return investors expect for taking risk: expected return − a safe (Treasury bill) return.
Systematic riskMarket-wide risk (recessions, rate hikes) that diversification can't remove.
Unsystematic riskRisk from one company or industry (a scandal, a recall) that diversification can remove.
BetaHow much a stock moves with the market. Beta 1.5: about 1.5× the market's move.
CAPMExpected return = safe rate + beta × (market return − safe rate).
CorrelationHow two investments move together, from −1 (opposite) to 0 (unrelated) to +1 (together).
Modern Portfolio TheoryMix assets that don't move together to get the most return for each level of risk.
Efficient frontierThe set of portfolios with the highest expected return for each level of risk.
Efficient marketPrices already reflect public information, so beating the market consistently is very hard.
Behavioral biasesOverconfidence, loss aversion, herding, FOMO, anchoring and confirmation bias.
RebalancingSelling what grew and buying what lagged to get back to your target mix.
Investment policy statement (IPS)A written plan: goal, time horizon, risk tolerance, target mix and rules.
